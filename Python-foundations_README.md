# Python Foundations

> Practice exercises from **Cisco Python Essentials 1**  
> Focus: Building a solid base in Python syntax, variables, and basic operations.

## Overview

This repository contains my early Python practice work while completing the Cisco Python Essentials 1 course. The programs cover fundamental concepts such as literals, variables, arithmetic operators, and simple real-world calculations.

These exercises are the starting point before moving into more practical projects (automation scripts, AI tools, and full-stack applications).

## Topics Covered

- Python literals (integers and floating-point numbers)
- Variables and assignment
- Arithmetic operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
- Basic calculations and expressions
- Using `print()` for output
- Simple problem-solving with fixed values

## Programs

| File | What it does |
|------|--------------|
| `day01_literals_operators.py` | Arithmetic operations, rectangle area & perimeter, temperature conversion, bill + tax calculation |
| `day01_challenge.py` | Independent discount calculator — calculates subtotal, discount amount, and final price |

## How to Run

Make sure Python 3 is installed, then run:

```bash
python day01_literals_operators.py
python day01_challenge.py
```

If the `python` command doesn't work, try `python3` instead.
