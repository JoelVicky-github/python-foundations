\# Python Foundations



This repository contains my Python practice exercises while completing

Cisco Python Essentials 1.



\## Topics Practised



\- Python literals

\- Integers and floating-point numbers

\- Variables

\- Arithmetic operators

\- Basic calculations

\- Using `print()`



\## Programs



\### day01\_literals\_operators.py



Contains exercises involving:



\- Arithmetic operations

\- Rectangle area and perimeter

\- Temperature conversion

\- Bill and tax calculation



\### day01\_challenge.py



Contains an independent discount-calculator challenge.



It calculates:



\- Subtotal

\- Discount amount

\- Final price



\## How to Run



Run the foundational exercises:



```bash

py day01\_literals\_operators.py

```



Run the challenge:



```bash

py day01\_challenge.py

```



If the `py` command is unavailable, use `python` instead.
